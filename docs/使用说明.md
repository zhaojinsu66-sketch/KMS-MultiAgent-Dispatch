# KMS多控

把 **Claude 桌面版**、**Codex 桌面版** 同时开多份，每个窗口登录各自的账号，在一个列表里切换、登录、换号。

（早期版本里的「总指挥 / 命令行账号 / 虚拟机」已经去掉。窗口用“贴靠”：它还是正常的独立窗口，只是被摆到右边那一格的屏幕位置上，所以打字、对话框、浏览器全都正常。）

## 打开

双击 `AgentCommander.exe`（或桌面/开始菜单的「KMS多控」）。不需要安装，也不需要联网下载任何东西。

## 主界面

左侧只有一栏 **「账号调度」**，每一条就是一个独立的 Claude / Codex 窗口：

- **点一条**：没开就打开它，并把它摆到右边那一格的位置上；已经开着就切到最前面。
- 名字下面那行小字：`Claude 桌面版 · 已打开 / 未打开`。
- 名字可以直接改：选中后顶部那个输入框就是它的名字，改完自动保存。
- **「＋ 添加」**：再开一个 Claude 或 Codex 窗口（每个窗口一份独立数据目录）。
- **设置**：命令行路径、执行权限等。

右边那一格显示的就是那个窗口本身（它仍是独立窗口，只是位置被 KMS 管着，跟着 KMS 移动/缩放/收起）。

## 每个窗口是独立的

每个窗口有自己独立的数据文件夹，所以登录的是它自己的账号。几个窗口可以同时开着、同时干活，不用在一个应用里来回切换登录。

## 登录

选中窗口，点顶部 **「登录 ▾」**：

- **怎么登录（先看这个）**：步骤说明。
- **打开这个窗口专用的真空浏览器**：开一个独立的 Edge 窗口。它有自己的数据目录（跟你平时的浏览器完全分开），而且**会记住这个窗口自己的登录**——关掉以后随时能再打开同一个，不会丢。
- **把剪贴板里的登录链接交给这个窗口**：邮箱登录时用，先在邮件里复制链接再点。
- **退出登录 / 换个账号…**：把这个窗口的登录数据改名留档（不删除），重开一个未登录窗口。

用 Google 登录时：在应用窗口里点「Continue with Google」→ KMS多控会把网址接到那个专用浏览器 → 登录完浏览器问“要打开 Claude 吗”，点打开 → 浏览器自动关掉，回到应用。

## 打开、排列、删除

- **放进这里**：打开这个窗口并切到最前面。
- **放回桌面**：把窗口摆回桌面上一个正常位置。
- **全部放回桌面并排**：所有窗口在屏幕上从左到右排好。
- **删除**：删掉这一条，连同它的登录数据。

## 数据放在哪

默认在 `%LOCALAPPDATA%\KMS\data`（换安装位置、升级都不会丢）。

- 如果你把 `data` 文件夹放在 exe 旁边，程序会优先用它（绿色版用法）。
- 也可以在 exe 旁边放一个 `datadir.txt`，里面写一个目录路径，程序就用那个目录（安装时会把旧数据目录写进去，这样安装版和旧版共用同一份登录）。

每个窗口的数据在 `<数据目录>\real-apps\<窗口编号>`，登录浏览器在 `<窗口编号>-browser`。

## 需要知道的事

- 多个窗口在同一个项目文件夹里同时改同一批文件会互相覆盖。
- 用多个订阅账号叠加用量是否符合各家服务条款，需要你自己确认。
- 本程序不保存、不转发你的密码和登录令牌：登录全程在各家官方应用自己的窗口里完成。

## 修改和重新编译

源码在 `src\` 和 `ui\`。用 Windows 自带的编译器即可：

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

`AgentCommander.exe --selftest 日志路径` 可以跑一遍不调用模型的自检。
