# KMS · 账号调度

一个 Windows 桌面程序：把官方的 **Claude 桌面版**、**Codex 桌面版** 同时开多份，每个窗口登录各自的账号，全部在一个界面里切换、排列、登录。

（以前版本里的「总指挥 / 命令行账号」已经去掉，现在只有窗口这一种账号。）

## 打开

双击 `AgentCommander.exe`（或桌面上的 KMS 快捷方式）。不需要安装，也不需要联网下载任何东西。

## 主界面

左侧只有一栏 **「账号调度」**，每一条就是一个独立的 Claude / Codex 窗口：

- 点一条：没开就打开它，已经开着就切到它，并把它嵌到右边那一格里。
- 名字下面那行小字：`Claude 桌面版 · 已打开` / `未打开`。绿点是已打开，灰点是没打开。
- 名字可以直接改：选中后顶部那个输入框就是它的名字，改完自动保存。
- **「＋ 添加」**：再开一个 Claude 或 Codex 窗口。
- **设置**：命令行路径、执行权限等程序设置。

打开程序时右边会提示「在左边选一个窗口」，选一个就开始。

## 每个窗口是独立的

每个窗口有自己独立的数据文件夹（`data\real-apps\` 下），所以登录的是它自己的账号。几个窗口可以同时开着、同时干活，不用在一个应用里来回切换登录。

## 给窗口登录账号

新开的窗口是未登录状态。选中它，点顶部的 **「登录 ▾」**：

- **怎么登录（先看这个）**：看一遍步骤；点“确定”后，这个窗口专用的浏览器会直接开在窗口里。
- **打开这个窗口专用的真空浏览器**：浏览器开在窗口里（Edge 访客模式 + 独立数据目录），里面没有任何已登录的账号、收藏和插件。
- **把剪贴板里的登录链接交给这个窗口**：先在邮件里复制登录链接，再点这里。
- **备用办法：搬数据的登录向导**：真空浏览器走不通时用，只动文件夹名字，不删东西。

两条登录路径：

- **用 Google 登录**：窗口里点「Continue with Google」→ KMS 把网页接到这个窗口的浏览器里 → 在弹出的那个浏览器里登录 → 登录完浏览器问“要打开 Claude 吗”，点“打开” → 结果交给这个窗口 → 自动关掉浏览器、切回应用。
- **用邮箱登录**：窗口里输入邮箱 → 点「登录 ▾ → 打开这个窗口专用的真空浏览器」，在里面开邮箱点链接；或者复制邮件里的链接，点「把剪贴板里的登录链接交给这个窗口」。

Codex 窗口不需要这些额外步骤：在它自己的窗口里正常点登录，结果会自己回到对的窗口。

浏览器开着的时候，顶部会多一个 **「返回应用 / 登录浏览器」**，在应用画面和浏览器之间来回切。

## 打开、放回、排列、删除

- **放进这里**：打开这个窗口并嵌进 KMS。
- **放回桌面**：把它拿出来，变回独立窗口。
- **全部放回桌面并排**：所有窗口拿出来，在屏幕上从左到右排好。
- **删除**：删掉这一条，连同它的登录数据（`data\real-apps\` 里那个文件夹）。

关闭 KMS 时，嵌在里面的窗口会自动放回桌面，不会跟着被关掉。

## 需要知道的事

- 几个窗口在**同一个项目文件夹**里同时改同一批文件，会互相覆盖。重要项目先备份，或者错开改。
- 用多个订阅账号叠加用量是否符合各家的服务条款，需要你自己确认。
- 本程序不保存、不转发你的密码和登录令牌：登录全程在各家官方应用自己的窗口里完成。

## 结果在哪里

每个窗口的数据在 `data\real-apps\<窗口编号>`，登录用的浏览器数据在 `data\real-apps\<窗口编号>-browser`。

## 修改和重新编译

源码在 `src\` 和 `ui\`。用 Windows 自带的编译器即可，不需要安装开发工具：

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

运行 `AgentCommander.exe --selftest 日志文件路径` 可以跑一遍不调用模型的自检。
